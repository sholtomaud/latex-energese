# Cleanup proposal and plan

Status: **decisions taken, partly executed.** Section 3 records what has been
done and what remains. The inventory in section 2 describes the repository as it
was before the cleanup began, so the reasoning behind each decision stays
legible.

---

## 1. Where things stand

The question that prompted this was whether to restart the package from
scratch. My answer is no, and it is worth recording why, because it shapes
everything below.

The layout engine in `energese-core.lua` — transformity columns, the
central-spine longest-path algorithm, heat sinks, system boundaries — was
already correct. It was verified standalone under Lua 5.5 against every JSON in
`examples/` and `tests/fixtures/` before any change was made, and it has needed
no algorithmic change since. That is the expensive part of this package, and
rewriting it would re-derive working code.

What was broken was everything around it. Fixed this session, all verified by
building in the `ubuntu-latex` container:

| Area | Was | Now |
| --- | --- | --- |
| Authoring | JSON only | JSON *and* TeX, sharing one model and one renderer |
| Symbols | Fixed size; labels overflowed | Size to their label; `minimum width/height` is a floor |
| Producer geometry | Rounded left, pointed right | Rectangle with a semicircular right end, per Odum |
| Consumer geometry | Pointed top/bottom, left notch | Hexagon pointed left and right, per Odum |
| Heat sinks | Requested a `heat_sink` anchor on `box`/`ground`, which have none | Only the four dissipating types are wired up |
| Money feedback | Style hardcoded `out/in/looseness`, fighting per-edge bends into full circles | Style is appearance-only; routing supplied per edge, with a sane default |
| Edge labels | `sloped` by default, so vertical pathways read sideways | Horizontal by default; `sloped` still available per edge |
| `\renderEnergese` | Leaked two interword spaces into every diagram, padding the bbox ~36pt | Clean |
| Path resolution | Tied to the compile directory | Falls back through `kpsewhich` |
| Font | Bare `\setsansfont` aborts where `tex-gyre` is absent | Guarded with `\IfFontExistsTF` |
| Build | No entry point | `make examples / docs / test / parity / check` |

The architectural guarantee is now enforced rather than asserted: `make parity`
rasterises the JSON and TeX versions of the same diagram and fails the build if
they differ by a single pixel. Both pairs currently pass.

**Remaining known gaps** — not yet addressed, listed so they are not lost:

- `aggregated-economy` still differs from Odum's original in edge-routing
  detail. Money arcs land near the producers' caps and two `$` labels sit on
  their pathways. This is example tuning, not a library defect.
- The test suite is almost entirely *compile-only*. Nine suites assert that a
  document builds and that four error messages fire. Only `make parity`
  asserts anything about appearance, and only for two diagrams.
- `tests/unit/test_shapes.tex` exercises the producer and consumer whose
  geometry changed. It passes, but only because it checks compilation — it
  would not have caught the wrong shapes.

## 3. Actions

Cleanup policy, as decided: **files are moved to `temp/`, not deleted.**
`temp/` is git-ignored, so quarantined files persist on disk, stay out of the
package, and remain recoverable without digging through git history.

| File | Why |

reading is not achievable against 144 DPI captures.

`.gitignore` now covers LaTeX output, rendered diagrams and `temp/`.

## 4. Way forward

**Done since this document was written:**

- The fidelity harness exists: `tests/fidelity/` with both tiers, wired into
  `make check`. 18 goldens, 6 symbols conforming, side-by-side comparison
  panels, and a contact sheet.
- Symbol geometry is now measured rather than eyeballed. Conformance
  immediately caught a wrong consumer topology that every existing test passed.
- The remaining build artifacts are untracked; only `docs/energese_user_guide.pdf`
  remains tracked, by decision.
- `docs/article.tex` drafts the *Ecological Modelling* submission, with figures
  generated by the harness.
- `docs/gssk-interop.md` records the GSSK format alignment.

**Also done in this round:**

- All nine of Odum's flow symbols implemented: `gain`, `loop_limited` and
  `switch` added and measured.
- Symbol outlines matched to Odum's pen weight (`\energeselinewidth`, 0.9pt),
  measured as a constant 2px at 144 DPI regardless of symbol size.
- The environmental floor line was wrong. Dissipation now converges on a single
  ground symbol, always placed outside the system window.
- Glyph scaling made consistent: the consumer's height multiplier was re-derived
  from 2.17 to 1.616, matching Odum's own 1.69 consumer-to-producer ratio.
- Conformance now asserts two invariants -- aspect ratio and interior overlap --
  on all nine symbols, with thresholds calibrated from measured agreement.
- `aggregated-economy` exists in both front ends and is in the parity set, so
  the complex case is covered, not just the simple ones.

**Also done in this round:**

- **Grid sizing.** `\energeseunit` sets a common floor; each symbol's minimum is
  the multiple of a cell at which its bare form lands on Odum's measured
  relative height. Rendered heights now agree with the reference to within 0.02,
  asserted by a third invariant.
- **Renderer bug fixed.** `render()` emitted each node twice -- an empty-labelled
  placeholder to establish coordinates, then the real one on top. Since symbols
  size to their labels, the placeholder was smaller, so every edge aimed at the
  wrong anchor: arrowheads were painted over and pathways cut through symbols.
  Nodes are now emitted once and pathways go on the background layer.
- **Pathway routing.** `energese.route` takes pathways *around* any symbol that
  is not their own endpoint. This is semantics, not tidiness: in ESL a line
  meeting a symbol denotes flow into it, so a pathway crossing an unrelated
  symbol asserts a connection the model does not contain. An intermediate fix
  put pathways on a background layer, which was wrong for exactly that reason --
  hidden is not the same as absent.
- Waypoints are joined by curves whose tangents follow the chord through each
  point, and unrouted edges get a slight bend, so no pathway is dead straight.
- Consumer aspect capped at 1.15 so a wide label cannot flatten the hexagon past
  anything Odum draws (his labelled consumers measure 1.09-1.12).
- Arrowheads enlarged to 5.8pt x 3.9pt: visible, still discrete.
- Heat-sink pathways drop vertically before converging, with more clearance, so
  the curve no longer kinks.
- Interaction symbols added to `aggregated-economy` in both front ends.
- `make fonts` asserts `TeXGyreHerosCondensed` is embedded, closing the silent
  font-fallback hazard.
- `REQUIREMENTS.md` rewritten: every requirement names the check enforcing it,
  and the ones with no check say so.
- The `font=` key trap fixed in the shipped example and documented.

**Also done in this round:**

- One arrowhead and one width for every pathway, dissipation included. The
  arrowhead is `Triangle`, not `Stealth`: Odum's pen drew a blunt solid head,
  and the ground terminator already used one, so the two disagreed.
- Heat-sink drop measured from the symbol's underside rather than its centre. A
  drop shorter than the half-height ran back *up* inside the glyph, which is why
  the consumer's pathway appeared to start off its outline.
- Node label font reduced to `\sffamily\small` via `\energeselabelfont`.
- `short_label` added, holding Odum's nomenclature (Q, X, J), with
  `metadata.label_mode` = long | short | both.
- A label larger than its grid cell is placed outside the symbol instead of
  inflating it, and joins the obstacle set so pathways route around the text.

**Also done in this round:**

- One arrowhead for the whole dissipation bundle. Giving every heat pathway its
  own head implied several separate flows arriving at the ground; they are one
  converging flow, so the head belongs at the terminator alone.
- Label font reduced to `\sffamily\footnotesize`, and `CM_PER_CHAR`
  recalibrated with it -- the width estimate feeds both label fitting and
  obstacle sizing, so it has to track the font.
- Interaction point and notch deepened to 0.85H and 0.55H. Sharper angles, same
  bounding proportions; measured overlap with Odum's symbol rose 0.934 -> 0.976.
- Consumer aspect cap tightened 1.15 -> 1.08. A single-line label at 1.15 left
  the hexagon looking stretched even though a two-line label at the same ratio
  did not.
- Displaced labels now pick the side with fewer collisions against symbols and
  pathways, rather than always sitting below.
- Label displacement threshold set to 1.6 cells. At the cell itself it fired on
  "Environmental Systems", which Odum writes inside its producer.
- The paper's symbol comparison laid out in three columns instead of one, and
  its caption now says stroke weight is not comparable between the panels.

**Also done in this round (from `docs/article_notes.tex`):**

- **Energetic validation added** -- `check_energetics` runs four topological
  checks (quality monotonicity, source/ground direction, reachability, dead
  ends), warning by default and erroring under `metadata.strict`. This closes
  the gap between the package's stated motivation and what it actually did,
  which was schema validation only.
- It immediately caught a real error in `aggregated-economy`: an interaction fed
  by a Tr=1000 source had been given Tr=500. Fixed in both front ends.
- `material` pathways exempted from the quality rule -- degraded material moving
  to a decomposition store genuinely falls in transformity, and applying the
  rule to it produced a false positive on `complex_industrial`.
- **Vertical placement made rule-based rather than arbitrary.** Layers are
  derived from a node's role relative to the main chain (feeds it from equal or
  higher quality -> above; receives from it and terminates -> below), with
  `layer_hint` as an explicit override that now wins even over spine membership.
- Fan order changed from alphabetical to declaration order: sorting by id made
  the layout depend on what nodes were called.
- The implied-syntax decisions are recorded in AGENTS.md 4a and the validation
  scope in 4b, so they cannot drift silently.

**Also done in this round:**

- **Edge `waypoints`** added, so a visual editor's geometry survives into the
  rendered figure. With `x`/`y` on nodes this closes the round-trip: a model may
  carry complete geometry, none, or a mixture.
- Article restructured around `docs/article_notes.tex`: ESL origins and the
  prior-tooling history, a semiotic frame (Morris, Goodman, Bertin, Harel,
  Moody), the ground-symbol anomaly demonstrated with a live figure, a RACI
  table, editor round-tripping, and a formalisation roadmap.
- The conventions and the checks are now documented in the CTAN guide as well as
  the paper -- the guide states what is implemented, the paper argues about it.
- Bibliography carries real citations for the notation-theory references;
  Valyi, the Hall draw.io template and GSSK are marked placeholders with notes
  on what each needs.

**Also done in this round:**

- **Shape invariance.** Symbols now hold their measured aspect at every size:
  each declares its aspect and its text capacity, and `\energese@fit` returns
  the smallest outline at that aspect containing the label. Verified across
  label lengths and magnitudes -- consumers measure 0.874-0.880 against a
  canonical 0.877, where they previously reached 1.15. The earlier aspect *cap*
  only bounded the distortion; it did not remove it.
- **`energese magnitude` scales the symbol, not the label.** TikZ's `scale` took
  the text with it, so equal labels came out in different type sizes.
- Producer-to-consumer height is now 0.770 against Odum's measured 0.765.
- Dissipation converges inside a system window so a **single line** crosses the
  frame, rather than each pathway crossing separately.
- The unused-energy branch is in the flagship example: energy reaching a source
  but not used by the system, which Odum draws leaving without driving anything.

**Also done in this round:**

- **Exchanges implemented.** A `transaction` naming a `seller` and a `buyer`
  expands into the four half-pathways of Odum's exchange: goods one way, money
  the other, coupled at the diamond. Expansion runs before validation, so the
  synthesised legs are checked, routed and drawn like declared ones and no
  special case appears downstream. The flagship example now uses two of them.
- **Author-bent pathways are collision-checked.** `clear_bend` keeps the
  author's direction of curvature and opens the angle in 8-degree steps until
  the curve clears, falling back to the router only if none does. The collision
  test reconstructs TikZ's own cubic rather than testing the straight chord.
  This removed the pathway that crossed the Agriculture symbol.

**Also done in this round:**

- **Exchange legs run parallel.** Goods and money now travel as a couple with
  the money just outside, which is Odum's visual signature for a transaction.
  The earlier version bowed them to opposite sides because `bend left` is
  relative to direction of travel and the two legs run opposite ways.
- Agriculture is now a seller: coupled pairs leave the top of its symbol, where
  previously it had no money pathway at all.

**Also done in this round:**

- **The exchange diamond was wrong and is now a marker.** Goods run seller to
  buyer as one continuous pathway with the diamond riding it at the midpoint,
  rotated to the flow, lines cutting through the glyph. The previous version
  terminated pathways at the diamond's anchors, which made it a component;
  Odum's is punctuation on a pathway. It follows that it has no transformity,
  no heat sink, is not an obstacle, and is never placed as a standalone node.
- **`make overlay`** puts a render over the published figure, reference red and
  render blue. A review aid, not a test -- there is no ground truth in a
  hand-drawn scan to score against.
- The overlay immediately earned its keep: it showed symbols at 0.35x Odum's
  relative size, and chasing that found a real regression -- `source` and
  `storage` had been missed when `energese magnitude` replaced TikZ's `scale`,
  so they silently ignored magnitude. Symbol conformance had passed throughout,
  because it measures bare symbols where magnitude never enters.
- With that fixed and the example's coordinates tightened, relative symbol size
  went 0.047 -> 0.110 against Odum's 0.134, and diagram aspect 1.52 -> 1.33
  against 1.37.

**Also done in this round:**

- **Connection ring** on every symbol: points spaced a constant distance apart
  along the outline (`\energeseanchorpitch`, 3mm), indexed `ring0` upward, so a
  larger symbol carries more of them and a coupled pair attaching at adjacent
  indices is separated by the same distance whichever symbol it meets.
- Spacing is by arc length, not angle. An angular ring was built first and
  discarded: it separates points further on large symbols than small ones,
  which is the opposite of what coupling needs.
- Figure 7 now shows the ring in red against the named anchors in black. The
  contact sheet is rasterised in colour for this; goldens stay greyscale.

## 5. Known defects not yet fixed

- **Pathway crossings are still not minimised.** The router avoids symbols and
  displaced labels; it does not yet reason about other pathways, which is the
  third of the three stated priorities. Symbol avoidance now covers author-bent
  pathways as well as automatic ones; pathway-versus-pathway does not.
- **`aggregated-economy` shows two money inflows at Agriculture; Odum's figure
  shows three.** Two exchanges there are defensible from the model -- Agriculture
  sells to Industry and to the consumer sector. The third inflow in Odum's
  figure cannot be reconstructed reliably from a 144 dpi scan: the corridor
  above Agriculture carries a bundle of coupled pairs and it is not certain
  which terminate there and which merely pass through. Adding a third sale to
  match a visual count would be inventing a transaction the model does not have.
- **Symbols remain slightly small relative to the diagram** (0.110 against
  Odum's 0.134) and the exchange diamonds read longer than his, because
  `sloped` stretches a 2.226-aspect glyph along the pathway.
- **The connection ring is approximate on two symbols.** The switch's bowed
  sides use an interpolation that still sits marginally outside the curve near
  the corners, and the interaction's notch is non-convex so the half-plane
  construction returns points slightly inside the drawn edge at the upper- and
  lower-left. Both are visible in Figure 7 and neither affects the named anchors.
- **The exchange legs do not yet use the ring.** Coupling them to adjacent ring
  indices is the reason the ring exists, and is the obvious next step.
- **Bibliographic placeholders.** Valyi's emergy simulator, the Hall draw.io
  template repository, and a GSSK software citation. Marked in
  `docs/article.tex`; the paper cannot be submitted without them.
- **Obstacle extents for routing are estimated**, not measured: Lua cannot know
  what TeX will typeset, so extents come from the grid plus a per-character
  label estimate, with `clearance_w`/`clearance_h` as the override. Exact
  extents would mean round-tripping node dimensions through the `.aux` file.
- **The container image digest is unpinned**, so goldens are strictly comparable
  only within one TeX Live installation. This is the last open item in the
  reproducibility story.
- `aggregated-economy` still differs from Odum's original in one routing
  detail: the fuels pathway arrives diagonally rather than vertically.
